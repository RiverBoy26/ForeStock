# Model Card: Nonton v7.4

- **Задача:** количество продаж `quantity` по складу, артикулу, неделе, девять недель.
- **Версия:** v7.4 FULL-history, chosen `META_P0.550_V0.15_A7`.
- **Training cutoff:** 2026-07-26; 13 543 строк продаж после cutoff исключены. Никакого будущего stock/price/channel в признаки.
- **Артефакт:** 39 LightGBM base + 2 LightGBM META; snapshot 134 исторические недели, 8 789 пар.
- **Валидация:** 7 девятинедельных непересекающихся окон; 2 warm-up + 5 forward for META; holdout 2026-05-25 используется только для отчёта (ранее изучался).
- **Выбранная META:** threshold .55; conditional volume blend .15; apply only activity>=7/13.
- **Средние результаты пяти forward окон:** SMAPE 60.6855%; WAPE 50.7633%; RMSE 2.6866; Bias 76.9856%; RMSLE 0.52125. Это **локальная история**, не метрики скрытого конкурсного периода.
- **Майский многократно просмотренный holdout:** selected: SMAPE 59.352%, WAPE 47.194%, RMSE 3.2712, Bias 75.418%, RMSLE 0.5121. Эту выборку не считать независимым benchmark.
- **Ограничения:** ассортимент фиксирован; дистрибуционный сдвиг, промо, новые склады, логистика, товары и каналы могут испортить прогноз; заметна слабая индивидуальная динамика горизонтов и недопрогноз при резком росте спроса.
- **Риски:** коммерчески чувствительная история в snapshot; невидимые конкурсные факты неизвестны; предсказанные количества не должны использоваться как гарантированная потребность без правил управления запасами.
- **Ответственность:** разработчики контролируют инфраструктуру, обновление, monitoring drift/quality, питание системы актуальными данными, rollout и rollback.
