# Нонтон — экспериментальное улучшение сигнатурной CatBoost

Версия 31.10.2026. **Сохранён оригинальный официальный прогноз №5.** Новая модель (`v8.2`) — отдельный исследовательский кандидат, неофициально не проверенный.

## Идея

Не трогать 39 базовых LightGBM и исходную CatBoost-классификацию `P(sale>0)`. Добавить **третью CatBoost-голову**, которая учится прогнозировать `log1p(quantity)` **только при положительных фактических продажах**. Она отличается целевой постановкой от существующего регрессора, который обучался в том числе на нулях.

При обучении новой головы использованы семь сохранённых исторических OOF-окон исходного ансамбля; в каждое окно базовые LightGBM прогнозировали без будущих целевых значений. В итоговой системе новая голова участвует в положительном прогнозе с весом:

`weight = 0.60 * clip((P(sale>0) - 0.53)/0.45, 0, 1) * clip(hybrid_raw / (hybrid_raw + 4), 0, 1)`

`amount = (1-weight) * original_amount + weight * positive_only_amount`

Затем **неизменённая** CatBoost постобработка: порог продажи 0.53, ограничение отношения к базовому прогнозу, смешивание на 50%, минимум единица товара при положительном решении. Нулевая маска точно совпадает с исходным конкурсным CSV.

## Как запустить Windows

Распаковать полный архив, открыть PowerShell в корне `Nonton_V82_EXPERIMENTAL`:

```powershell
powershell -ExecutionPolicy Bypass -File .\install_windows.ps1
powershell -ExecutionPolicy Bypass -File .\run_v82_windows.ps1
```

Первый скрипт устанавливает библиотеки в `.venv`, второй сверяет оригинал, создаёт новый CSV, сверяет его с эталонной сборкой и запускает тесты.

*Новый прогноз:* `forecasts/v82_confidence_amount.csv`. *Оригинал:* `forecasts/v81_catboost.csv`.

Переобучить только новую модель на сохранённых OOF, не трогая все 41 старую модель:

```powershell
powershell -ExecutionPolicy Bypass -File .\run_v82_windows.ps1 -Refit -Threads 3
```

Чтобы повторить полный backtest с пяти последовательных folds (при каждом fold переобучаются обе старые CatBoost-головы и новая условная голова только из более ранних OOF):

```powershell
powershell -ExecutionPolicy Bypass -File .\run_v82_windows.ps1 -Forward -Threads 4
```

Если требуется выполнить инференс с пересчётом 39 LightGBM из весов, а не с замороженного кэша:

```powershell
.\.venv\Scripts\python.exe -m app.v82_inference --verify --recompute-base
```

## Ограничения

* В этом архиве `history_snapshot` заканчивается 26.07.2026, а прогноз привязан к 27.07–27.09.2026. Это frozen-inference, не динамическая модель для произвольных новых загруженных CSV.
* Артефакты исходной модели содержат агрегированные коммерческие данные; не публиковать ZIP в открытом доступе.
* Этот кандидат сильно коррелирует с исходным прогнозом: он **не решает полностью** проблему недостаточно чувствительного к тренду исходного ансамбля.
* Результаты выбора могли подстроиться под многократно изученные исторические периоды. Победа над оригиналом в официальном Score не доказана.
