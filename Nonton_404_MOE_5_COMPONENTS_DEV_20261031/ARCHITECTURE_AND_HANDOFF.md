# Передача пятикомпонентной исследовательской модели

## Контекст чекпоинта

На чекпоинте была представлена пятиблочная исследовательская концепция: точечный SKU-прогноз, независимая нейромодель, прогноз динамики категории, обучаемая маршрутизация и коррекция объёма. Описание относится к архитектурному направлению исследования, но **не является техническим описанием файла «прогноз №5»**. Тот официальный файл создан v8.1 (39 LightGBM и 2 CatBoost); этот пакет содержит другой, отдельно обученный эксперимент. Указание версии требуется во всех демонстрациях, графиках и интеграции.

## Восстановление исходников

Исходный исследовательский архив MOE из предыдущего эксперимента сейчас недоступен в исполнимом виде. Вместо него передаётся **новая реконструкция**, проверенная полным пользовательским запуском `results_MOE_FULL`: семь OOF-окон, финальные веса, 4 CSV, исторические отчёты. Не выдавать реконструкцию за архив оригинального MOE и не приписывать её показатели официальному лидерборду.

## Рабочие параметры

См. `training_config.json`, `reports/manifest.json`. Пять функциональных компонентов и шесть обученных файлов: SKU probability + positive qty, NN, macro Poisson, router binary, Tweedie corrector. Финальный параметр коррекции 15%. Макромодель изменяет форму недель, но не абсолютный суммарный спрос. Жёсткая маска нулей сохраняется. Количество продаваемых единиц возвращается как float, **не округлять** без повторного теста.

## Что известно по качеству

`reports/historical_metrics.csv` содержит статистику на исторических OOF-окнах. Последние четыре окна используют метамодели, обученные только на более ранних OOF; первые три имеют только базовую оценку. Официальных истинных значений для девяти конкурсных недель у нас нет. Бэк-тесты сами по себе не доказывают превосходства над v8.1.

## Система разработки

При интеграции не подменять вычисление live-прогноза выдачей заранее рассчитанного CSV. Frozen replay нужен для демонстрации и верификации переданных весов, для нового периода необходим отдельный as-of pipeline. Не смешивать тренировочные или тестовые результаты из разных `--out`.
