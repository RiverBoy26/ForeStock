# ForeStock

## Запуск через Docker Compose

Требуется запущенный Docker Desktop.

```powershell
docker compose up --build -d
```

После запуска доступны:

- фронтенд: http://localhost:8080
- бэкенд: http://localhost:8000
- проверка бэкенда: http://localhost:8000/health
- ML API и Swagger: http://localhost:8082/docs
- PostgreSQL: `localhost:5432`

## Связь компонентов

Форма на фронтенде отправляет оба выбранных CSV-файла на `POST /predict`.
Фронтенд проксирует multipart-запрос в контейнер бэкенда по адресу
`http://backend:8000/predict` и возвращает полученный CSV пользователю для
скачивания.

Бэкенд проверяет и сохраняет исходные данные, после чего передаёт их контейнеру
`ml` на `POST /v1/predict`. Перед отправкой backend оставляет только последние
52 полные недели — минимальное окно истории, необходимое модели. ML-сервис
Nonton v7.4 строит динамические признаки,
запускает 41 сохранённую LightGBM-модель и возвращает прогноз на девять недель.
По умолчанию используется вариант `selected`.

Ограничения модели:

- каждый загружаемый CSV-файл — не более 500 МБ;
- история продаж должна охватывать минимум 52 недели;
- склады и артикулы должны присутствовать в зафиксированном справочнике модели;
- веса модели не переобучаются при запросе, используются только новые признаки;
- можно выбрать любой непрерывный промежуток внутри горизонта модели: с 1-й по 9-ю неделю.

Посмотреть состояние и логи:

```powershell
docker compose ps
docker compose logs -f
```

Остановить контейнеры:

```powershell
docker compose down
```

Удалить контейнеры вместе с данными PostgreSQL и загруженными файлами:

```powershell
docker compose down -v
```

Настройки по умолчанию можно изменить, скопировав `.env.example` в `.env`.
